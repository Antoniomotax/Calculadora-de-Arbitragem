# Calculadora de Arbitragem

Este aplicativo é uma Calculadora de Arbitragem  desenvolvida em HTML, CSS e JavaScript, com suporte completo a **PWA**, permitindo instalação em **Android**, **PC** e navegadores compatíveis.

Ele permite calcular automaticamente os valores ideais de aposta em duas casas diferentes para garantir **lucro sem risco**, explorando diferenças de odds entre elas.

---

## 🚀 Funcionalidades

* Cálculo instantâneo de arbitragem entre duas odds
* Interface moderna estilo aplicativo
* 100% offline após instalado
* Instalável no Android e PC (PWA)
* Zero cadastros ou anúncios
* Fácil de usar, rápido e leve

## 📱 Instalação (PWA)

### **Android**

1. Abra o app no navegador Chrome
2. Toque no menu (⋮)
3. Clique em **Adicionar à tela inicial**
4. Confirme a instalação

### **PC (Windows / Mac / Linux)**

1. Abra no Chrome ou Edge
2. Clique no ícone de instalação na barra de endereço
3. Confirme para instalar como aplicativo

---

## 🧮 Como Usar

1. Informe a **Odd 1** (Casa de Aposta A)
2. Informe a **Odd 2** (Casa de Aposta B)
3. Informe o **valor total que deseja apostar**
4. O app calcula automaticamente:

   * Valor ideal para apostar em cada casa
   * Percentual de retorno
   * Lucro garantido
